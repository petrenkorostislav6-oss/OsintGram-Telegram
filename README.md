# OsintGram

**Telegram client** with enhanced anonymity, full Ghost Mode, plugin support and planned built-in OSINT tools.

Based on [AyuGram](https://github.com/AyuGram/AyuGramDesktop).

## Planned features
- Full Ghost Mode (hide online, typing, read receipts, story views)
- Advanced anonymity settings
- Plugin system (compatible with AyuGram/ExteraGram plugins)
- Built-in OSINT tools (Instagram + Telegram) — coming later
- Custom branding as OsintGram

## Current status
Repository created. Next steps: fork base client and rebrand.
